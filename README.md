# entry-u-ronigrv-a-day-of-one-line-pitches-12cd9bb3 — A Day of One-Line Pitches

One sentence for make.fun's "A Day of One-Line Pitches" bounty: a
pitch to a friend who has never coded, to let an AI agent build
their first app idea on make.fun.

> Tell me your app idea in plain words and I'll have an agent build you a working first version on make.fun today, so you can try it tonight before you spend a cent or write a line of code.

Why it should persuade: a concrete reason to say yes now (a
working first version today), low risk (try it tonight before
spending anything), plain words with no jargon, and no
overpromising — it offers a first version to try, not a finished
product. One sentence, 187 characters.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13 standard library only, no network, no
randomness) writes the sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to `$MAKEFUN_OUTPUT`, then `/output`) and asserts the
competition's gate itself: one sentence, 1–240 characters. The
sentence is a fixed string, so two runs produce identical bytes.
